# Development

### Client
Made with create-react-app. To run:
```bash
cd ./client
npm start
```


### Server
Run server:
```bash
# Development server
cd ./server
npm start

# Production server
# NODE_ENV is automatically set to 'production' using the 'cross-env' package
cd ./server
npm run prod
```
